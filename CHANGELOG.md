# Что нового

## 1.0.0 — первая версия

### Для студентов
- Вход по логину или e-mail, регистрация, восстановление пароля по коду из письма, шкала надёжности пароля.
- Главная: приветствие по времени суток, «Продолжить обучение», серия дней, ближайшие сроки заданий, популярные и новые курсы, направления, новости.
- Каталог курсов с поиском и фильтрами, запись на курс и заявка с документом, выход из курса.
- Уроки: видео с продолжением с места остановки, код с подсветкой, PDF во встроенном просмотре, материалы для офлайна, обсуждение.
- ИИ-репетитор урока с ответом в реальном времени, выбором модели и историей.
- Тесты с таймером и разбором ответов, задания с загрузкой файлов, задачи по программированию в Monaco, онлайн-компилятор.
- Библиотека и читалка PDF/EPUB с заметками; «Моя полка».
- Новости, форумы, общий чат, уведомления Windows, достижения, рейтинг, сертификаты и их проверка.

### Для преподавателей и администраторов
- Кабинет преподавателя: курсы, уроки (порядок перетаскиванием), материалы, тесты, задания, задачи по программированию, ИИ-помощник автора, проверка работ, студенты, аналитика.
- Панель администратора: заявки, обращения, объявления, пользователи, аналитика, полная админка сайта с автоматическим входом.

### Приложение
- Три языка интерфейса: тоҷикӣ, русский, English.
- Светлая и тёмная темы, Mica, размер текста, уменьшение анимации.
- Офлайн-режим и очередь действий, глубокие ссылки `moodletj://`, трей, автозапуск, автообновление.
- Отдельный токен для каждого устройства: выход на компьютере не разлогинивает телефон.
